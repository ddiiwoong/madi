# 마디

보는 화면에서 **바로 고치는** 마크다운 편집기입니다. 캐럿이 있는 줄만 `원문`이 보이고,
나머지 줄은 문서처럼 그려집니다.

## 이렇게 보입니다

- [x] 마커는 캐럿이 떠나면 숨습니다
- [ ] 저장하면 원문이 한 바이트도 바뀌지 않습니다
- *기울임*과 ~~취소선~~도 그 자리에서

> 인용은 막대로, 코드는 블록으로 그립니다.

| 기능 | 단축키 | 상태 |
|:---|:---:|---:|
| 원본 보기 | ⌘E | 있음 |
| 번역 | ⌘⇧T | 있음 |
| 나란히 보기 | ⌃⌘T | 있음 |

```swift
let editor = MarkdownEditorView()
editor.markdown = "# 제목"   // 고치면 바로 그려진다
```
